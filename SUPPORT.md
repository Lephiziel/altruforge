# Support

## Where to start

- Product scope: [MVP brief](docs/product/mvp.md).
- Implementation: [agent entry point](docs/agents/START_HERE.md).
- Contracts: [specification](spec/README.md).
- Bugs and design proposals: [issue forms](https://github.com/Lephiziel/altruforge/issues/new/choose).
- Vulnerabilities: [security policy](SECURITY.md).
- Community concerns: [Code of Conduct](CODE_OF_CONDUCT.md).

There is no released CLI to install yet. Do not run installation commands copied from a concept or assume a package with the project name is maintained by this repository.

When asking for help, provide the task ID or commit, operating system, expected behavior, and relevant redacted output. Avoid uploading entire environment dumps or authentication files.
