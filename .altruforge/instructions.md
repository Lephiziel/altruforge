# Contribution instructions for a future Altruforge run

Read AGENTS.md and the selected task. Implement only the approved issue scope. Preserve public contracts unless the task explicitly changes them and updates the associated schemas, examples, and prose.

Do not edit the pinned project policy, workflow permissions, credentials, or licensing as part of an ordinary runtime-selected issue. Run required checks through the configured controlled executor. Report missing evidence honestly.

This file applies only after the project manifest is enabled and a compatible runtime is implemented.
