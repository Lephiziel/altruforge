# MVP-15 Record real end-to-end and contribution-quality evidence

Status: not implemented.
Dependencies: [MVP-11](MVP-11.md), [MVP-12](MVP-12.md), [MVP-13](MVP-13.md), [MVP-14](MVP-14.md)

## Outcome

Demonstrate the public MVP and measure whether the harness creates reviewable useful work.

## Acceptance criteria

- [ ] Run a complete task-to-Draft-PR scenario on Windows, macOS, and Linux using a designated repository/account and explicit budgets.
- [ ] Record versions, immutable revisions, configuration, observed results, limitations, and redacted artifacts.
- [ ] Exercise cancellation/recovery, quota/auth failure, lease conflict/expiry, and a lost publication response.
- [ ] Evaluate a preselected set of bounded tasks with acceptance criteria; include failures, setup/review time, manual fixes, and later regressions.
- [ ] Compare with the same coding tool and similar budgets where feasible, without claiming statistical certainty from a small pilot.
- [ ] Leave unmet release gates incomplete and get maintainer review of the actual PRs.

## Out of scope

Using unsuspecting upstream projects as test targets and fabricated benchmark/demo results.

## Required handoff

Reviewed public evidence records, honest task outcomes, and a release-gate assessment.

Use [the handoff template](../agents/HANDOFF.md). All changes and reports must be in English.
