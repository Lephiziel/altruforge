# Roadmap

The repository is in pre-implementation. These milestones describe required work, not shipped capability.

| Milestone | Work packages | Exit condition |
| --- | --- | --- |
| M0 Boundary and development foundation | MVP-01, MVP-02 | Supported boundary evidence and actual module/CI foundation |
| M1 Reliable local components | MVP-03 through MVP-07 | Validated policy, durable state, identity/workspaces, agent and executor |
| M2 Coordinated contribution | MVP-08 through MVP-13 | Leases, selection, bounded runs, checks, Draft PR handoff and CLI |
| M3 Public MVP | MVP-14 through MVP-16 | Tested packages, real cross-platform evidence and proven onboarding |

See [the ordered backlog](tasks/README.md) for acceptance criteria and dependencies.

## After the MVP

Additional supported agents, file-based task sources, a project directory/hub, native-platform build environments, richer UI, and opt-in handling of review feedback are candidates. Each needs an explicit scope and evidence. Automatic merging is not part of the current product contract.
